# BlocksCreate World

> **ITERATION / WORLD EXPERIMENT**

An early browser-world experiment in the BlocksCreate lineage. This repository preserves a stage where world and interaction ideas were explored independently before the larger project converged.

The current mature project is [blockscreate](https://github.com/joaoccaldas/blockscreate).

## What remains useful here

- early world-generation and interaction ideas;
- historical comparison with later BlocksCreate architecture;
- a small test bed for understanding how the game's world model evolved.

New reusable game infrastructure should normally be developed or extracted from the current BlocksCreate project rather than this snapshot.

## Project context

This is a personal, self-directed learning project by João Caldas. AI tools are used extensively during research, design, coding, debugging, testing, asset ideation, and documentation as part of the learning process. AI-generated suggestions are treated as inputs to review, not proof of correctness.
